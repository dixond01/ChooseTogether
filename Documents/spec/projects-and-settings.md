# Projects and Settings

Each project has its own team, tags, form and settings. Managers can edit the settings (see `roles-and-auth.md`).

| Setting | Default / example | Notes |
|---|---|---|
| Submission deadline (`submissions_close_at`) | required | The form closes after it, and managers can extend it. Auto-assignment runs at the deadline. |
| Max participants | null = no limit | Counts every participant on a submission. |
| Max duration (video/audio) | e.g. 300 s | Checked in the browser before upload. There is no max file size. |
| Reviewers per submission (N) | 2 | |
| Decision rule | **any disagreement → owner** | Alternative: majority decides. |
| Score required | per project (on for the talent show) | A 1–5 score with each vote. |
| Tags | predefined list | e.g. solo, group, music, singing, humor. Reviewers can only pick from this list. |
| Original-file retention | **keep until results are sent** | Other options: delete after conversion (optional grace period in days), or keep forever. Warn in the settings screen that deleting originals disables Reprocess. |
| Target show length | e.g. 90 min | Used for the time budget and the timeline. |
| Agreement text | per project | Shown with the form's checkbox. |
| Email templates | default text | One per final status. See `results-and-email.md`. |
