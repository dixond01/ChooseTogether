# CS 452 Final Project Requirements

- Spend 30–40 hours on it.
- Use AI to help build it.

## Things the project should be able to show or explain
- A data model (ERD) for the project's data.
- A system design: technology choices, security boundaries, scaling considerations and costs.
- Where it applies: failover strategy, scaling, performance, authentication and concurrency.
- Whether and how the project integrates with AI, and how AI was used to build it.
- A working demo (video or GIF).
